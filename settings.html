🔌 GitHub 連線

Token 只會儲存喺你瀏覽器嘅 localStorage，用嚟 dispatch workflow、讀寫 JSON 同更新 secret。需要權限：Actions（讀寫）、Contents（讀寫）、Secrets（讀寫，可選）、Metadata（讀）。

🤖 AI 模型設定

🚀 直連模式（幾秒出結果）同 Actions 後備模式都用呢個 model。
⚡ 最快：qwen/qwen3-vl-8b-instruct（預設）或 qwen/qwen3.8-flash（更快，可試）。
🎯 最準：qwen/qwen3-vl-30b-a3b-instruct（準但慢少少）。
❌ moondream* 太弱讀唔到細字；❌ openai/gpt-4o-mini、google/gemini-* 對「書頁文字」有 ToS 審查（403）。

支援任何 OpenAI 兼容嘅 /chat/completions 端點。
⚠️ 只需填到 …/api/v1 就夠，唔好連 /chat/completions 都填埋（系統會自動補上；填埋會變 404）。

儲存後會寫入 repository 入面嘅 config/settings.json，同時記低喺你瀏覽器（直連模式用）。
測試用嘅 Key 會優先取「🚀 瀏覽器直連」嗰個；未啟用就試「🔑 API Key」輸入框。測試只驗證連線同延遲，唔代表書頁 OCR 一定得（某啲 model 對書頁圖有 ToS 限制）。

🚀 瀏覽器直連（最快：幾秒出結果）

啟用之後：相片上傳後會由你嘅瀏覽器直接 call OpenRouter， 唔經 GitHub Actions，幾秒就出到 AI 結果；相片完全唔會離開你部機。
Key 只會儲存喺你瀏覽器嘅 localStorage（同你個 GitHub Token 一樣）， 唔會入 repository。
如果冇填呢個 Key（或直連失敗），會自動用返 GitHub Actions 後備模式（約 1–2 分鐘）。

🔑 OpenRouter API Key（GitHub Actions 後備用）

呢個係後備模式用：如果冇啟用瀏覽器直連，就會用 GitHub Actions 分析，呢個 Key 會用 GitHub Secrets API 加密寫入 OPENROUTER_API_KEY Actions secret（唔會入 repository）。
如果 Token 冇 Secrets 權限，可直接去 GitHub → Settings → Secrets and variables → Actions 新增 OPENROUTER_API_KEY。
