🤖 AI 模型設定

必需：相片上傳後由你嘅瀏覽器直接 call OpenRouter（幾秒出結果）， 相片完全唔會離開你部機。
Key 只會儲存喺你瀏覽器嘅 localStorage，唔會入 repository。

🏆 最穩（實測豎排螢光筆字全中）：qwen/qwen3-vl-235b-a22b-instruct；⚡ 最快：qwen/qwen3-vl-8b-instruct（快但有時錯字）。
⚠️ Qwen 視覺 model 係 vl（字母 V-L），唔係 v1（V-1）；打錯會「not a valid model ID」。
❌ moondream* 太弱讀唔到細字；❌ openai/gpt-4o-mini、google/gemini-* 對「書頁文字」有 ToS 審查（403）。

支援任何 OpenAI 兼容嘅 /chat/completions 端點。
⚠️ 只需填到 …/api/v1 就夠，唔好連 /chat/completions 都填埋（系統會自動補上；填埋會變 404）。

「儲存 AI 設定」會寫入 repo 嘅 config/settings.json（model／base URL）＋記低喺瀏覽器（Key 淨係記喺瀏覽器）。
「測試 Model」會用輸入緊嘅 Key ＋ Base URL ＋ Model 一併實際 call 一次驗證連線（20 秒內有回應先算過）。
